# 픽셀아트 가이드

게임 화면과 테마를 그릴 때의 기준이다. 값은 목업(`docs/mockup/*.html`)에서 쓴 것을 옮겼다. 새 테마나 오브젝트를 만들 때 여기 규칙부터 맞춘다. 바꿀 때는 이 문서를 먼저 고친다.

## 1. 화면과 좌표

| 항목 | 값 |
|---|---|
| 화면(뷰포트) | 114 × 227 픽셀 |
| 확대 배율 | 3배 (CSS 342 × 681), `image-rendering: pixelated` |
| 월드 크기 | 200 × 340 픽셀. 화면보다 크고 카메라가 따라감 |
| 좌표 단위 | 정수 픽셀. 그리기 직전에 반올림 (`Math.round`) |
| 카메라 | 캐릭터를 화면 가로 가운데·세로 절반에 두고 부드럽게 따라감(`dt × 5` 보간). 월드 밖은 보여주지 않음 |
| 이동 속도 | 초당 40픽셀 |

- **배경은 한 번만 그린다.** 땅·바다·숲처럼 움직이지 않는 것은 시작할 때 오프스크린 캔버스(월드 크기)에 그려 두고 매 프레임 통째로 붙인다.
- **매 프레임에는 움직이는 것만 그린다.** 캐릭터, 장식 애니메이션, 방명록 오브젝트 등이다.
- 같은 모양을 여러 번 쓰는 그림(나무 등)은 작은 캔버스에 미리 그려 두고 `drawImage`로 찍는다.

## 2. 그리기 순서

1. 배경 캔버스
2. 바닥에 붙은 효과 (물결 반짝임, 파도 거품, 방명록 오브젝트, 부두 같은 바닥 구조물)
3. **y정렬 레이어:** 건물, 나무, 장식, 캐릭터를 **발밑 y좌표** 순으로 정렬해 그린다. 그래야 캐릭터가 물체 앞뒤로 자연스럽게 지나간다.
4. 공중 효과 (나비, 갈매기, UFO, 별똥별)
5. HTML 오버레이 (이름표, 말풍선, 버튼, 모달)

- 오브젝트마다 "발밑 y"를 하나 정한다. 보통 그림의 가장 아래 줄이다.
- 충돌 영역은 **발밑 근처의 낮은 사각형**으로만 잡는다(건물은 벽 아래쪽, 나무는 줄기). 캐릭터는 발 위치 한 점으로 충돌을 판정한다.
- 이동은 x축과 y축을 따로 판정해서, 벽에 비스듬히 부딪히면 미끄러지듯 움직이게 한다.

## 3. 공통 스타일

| 항목 | 규칙 |
|---|---|
| 외곽선 | 모든 물체에 1픽셀 어두운 외곽선 `#2a1a2e` |
| 음영 | 4×4 Bayer 디더링. 빛은 왼쪽 위에서 비춤 |
| 색 수 | 물체 하나에 3~5색. 팔레트(5장) 밖의 색은 새로 만들지 않음 |
| 그림자 | 발밑에 납작한 타원. 바닥보다 한 단계 어두운 색, 또는 `rgba(20,40,20,.28)` |
| 안티에일리어싱 | 쓰지 않음. 선은 Bresenham, 원·타원은 줄 단위 사각형으로 그림 |
| 애니메이션 | 프레임을 끊어서 바꿈(2프레임 걷기, 깜빡임). 부드러운 보간은 카메라에만 씀 |

Bayer 행렬 (값 ÷ 16 = 0~1 임계값):

```
 0  8  2 10
12  4 14  6
 3 11  1  9
15  7 13  5
```

구형 음영(행성, 나무 수관)은 표면 법선과 빛 방향(왼쪽 위 앞)의 내적에 디더링 값을 조금 더해 5단계 팔레트 중 하나를 고른다. 가장자리 한 줄은 외곽선 색이다.

## 4. 스프라이트 표기법

작은 스프라이트는 **문자열 배열**로 정의한다. 한 글자가 한 픽셀이고 `.`은 투명이다. 글자마다 색을 매핑한다. 좌우 반전은 각 줄을 뒤집어 그린다.

```js
// 물고기 9×5, 머리가 오른쪽
const FISH = [
  '....kkkk.',
  'kk.kcccwk',
  'ktkccckck',
  'kk.kddddk',
  '....kkkk.',
] // k 외곽선, c 몸, d 배·꼬리, t 꼬리, w 반짝임
```

| 스프라이트 | 크기 | 비고 |
|---|---|---|
| 신랑 | 7 × 11 | 항상 왼쪽. 걷기 2프레임(다리 줄만 교체), 걸을 때 1픽셀 들썩임 |
| 신부 | 7 × 11 | 항상 오른쪽. 신랑과 반 박자 엇갈려 들썩임 |
| 물고기 (마을 방명록) | 9 × 5 | 색 6종. 멀리서는 한 가지 그림자 색으로 그림 |
| 별 (우주 방명록) | 1픽셀 + 십자 반짝임 | 새 별은 한 단계 크게 |
| 강아지 (마을) | 10 × 6 | 달리기 2프레임, 앉으면 꼬리 흔들기 |
| 거북이 (마을) | 15 × 7 | 옆모습. 다리 2프레임 |
| 나무 | 22 × 26 캔버스 | 구형 음영 수관 + 줄기. 꽃 핀 변형 있음 |

캐릭터 색 매핑:

| 글자 | 색 | 쓰임 |
|---|---|---|
| `k` | `#2a1a2e` | 외곽선 |
| `n` | `#2a2030` | 신랑 머리 |
| `N` | `#7a4a30` | 신부 머리 |
| `s` | `#f2c29a` | 피부 |
| `w` | `#f4efe6` | 셔츠·드레스 |
| `u` | `#2f3b62` | 정장 |
| `r` | `#d04a3a` | 넥타이 |
| `p` | `#f29bb5` | 부케·하트 |
| `y` | `#f6c85f` | 베일 장식 |
| `g` | `#c9c6c0` | 드레스 그림자 |

## 6. UI 색 (HTML 오버레이)

| 색 | 쓰임 |
|---|---|
| `#fbf3e4` | 모달·말풍선·버튼 바탕 |
| `#f6e7cc` | 칩 버튼 바탕 |
| `#e2d3b8` | 점선 구분선 |
| `#c8593c` | 모달 안 강조 글자(소제목, 이름) |
| `#6a5a4a` / `#9a8a7a` | 보조 글자 |
| `#2a2450` | 우주 테마 모달 헤더 |
| `#1e4660` | 마을 테마 모달 헤더 |

- 폰트는 갈무리11(Galmuri11, OFL). 글자 크기는 본문 11~14px, 헤더 이름 17px, 사진 썸네일 번호 9px.- 모서리는 둥글리지 않고 3px(모달 6~9px) **깎인 모서리**(`clip-path`)로 픽셀 느낌을 낸다.
- 테두리는 2px(모달 3px) `#2a1a2e`.
- UI 애니메이션은 `steps()`로 끊어서 움직인다.

## 7. 새 테마 체크리스트

1. `docs/PLANNING.md` 2장 테마 비교표의 칸을 모두 채운다.
2. 팔레트를 이 문서 5장에 추가한다.
3. 정할 것: 월드 배경, 이동 가능 영역, 장소 3곳의 좌표(들어가기 판정 반경 12픽셀), 충돌 영역, 시작 위치, 자동 이동 경유지
4. 방명록 오브젝트: 글 id 해시로 위치·색을 정하는 규칙, 새 글 연출, 탭 판정 반경
5. 장식은 적게 시작한다. 고정 장식 몇 개와 움직이는 장식 2~3개면 충분하다.
6. 모달 헤더 색을 정한다.
