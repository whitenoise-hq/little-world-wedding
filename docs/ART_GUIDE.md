# 픽셀아트 가이드

게임 화면과 테마를 그릴 때의 기준이다.

> **픽셀아트는 게임 화면에만 쓴다.** 움직이는 배경·캐릭터·오브젝트, 세계 안의 이름표·말풍선, 그리고 그 위에서 쓰는 조작(조이스틱, 플로팅 버튼, 들어가기 버튼)까지가 픽셀이다. 그 밖의 글자·버튼·모달·인트로는 차분한 청첩장 디자인(6장)을 따른다. 값은 목업(`docs/mockup/*.html`)에서 쓴 것을 옮겼다. 새 테마나 오브젝트를 만들 때 여기 규칙부터 맞춘다. 바꿀 때는 이 문서를 먼저 고친다.

## 1. 화면과 좌표

| 항목 | 값 |
|---|---|
| 화면(뷰포트) | 114 × 227 픽셀 |
| 확대 배율 | 3배 (CSS 342 × 681), `image-rendering: pixelated` |
| 월드 크기 | 200 × 340 픽셀. 화면보다 크고 카메라가 따라감 |
| 좌표 단위 | 정수 픽셀. 그리기 직전에 반올림 (`Math.round`) |
| 카메라 | 캐릭터를 화면 가로 가운데·세로 절반에 두고 부드럽게 따라감(`dt × 5` 보간). 월드 밖은 보여주지 않음 |
| 이동 속도 | 초당 40픽셀 |

- **배경은 한 번만 그린다.** 땅·바다·숲처럼 움직이지 않는 것은 시작할 때 오프스크린 캔버스(월드 크기)에 그려 두고 매 프레임 통째로 붙인다.
- **매 프레임에는 움직이는 것만 그린다.** 캐릭터, 장식 애니메이션, 방명록 오브젝트 등이다.
- 같은 모양을 여러 번 쓰는 그림(나무 등)은 작은 캔버스에 미리 그려 두고 `drawImage`로 찍는다.

## 2. 그리기 순서

1. 배경 캔버스
2. 바닥에 붙은 효과 (물결 반짝임, 파도 거품, 방명록 오브젝트, 부두 같은 바닥 구조물)
3. **y정렬 레이어:** 건물, 나무, 장식, 캐릭터를 **발밑 y좌표** 순으로 정렬해 그린다. 그래야 캐릭터가 물체 앞뒤로 자연스럽게 지나간다.
4. 공중 효과 (나비, 갈매기, UFO, 별똥별)
5. HTML 오버레이 (이름표, 말풍선, 버튼, 모달)

- 오브젝트마다 "발밑 y"를 하나 정한다. 보통 그림의 가장 아래 줄이다.
- 충돌 영역은 **발밑 근처의 낮은 사각형**으로만 잡는다(건물은 벽 아래쪽, 나무는 줄기). 캐릭터는 발 위치 한 점으로 충돌을 판정한다.
- 이동은 x축과 y축을 따로 판정해서, 벽에 비스듬히 부딪히면 미끄러지듯 움직이게 한다.

## 3. 공통 스타일

| 항목 | 규칙 |
|---|---|
| 외곽선 | 모든 물체에 1픽셀 어두운 외곽선 `#2a1a2e` |
| 음영 | 4×4 Bayer 디더링. 빛은 왼쪽 위에서 비춤 |
| 색 수 | 물체 하나에 3~5색. 팔레트(5장) 밖의 색은 새로 만들지 않음 |
| 그림자 | 발밑에 납작한 타원. 바닥보다 한 단계 어두운 색, 또는 `rgba(20,40,20,.28)` |
| 안티에일리어싱 | 쓰지 않음. 선은 Bresenham, 원·타원은 줄 단위 사각형으로 그림 |
| 애니메이션 | 프레임을 끊어서 바꿈(2프레임 걷기, 깜빡임). 부드러운 보간은 카메라에만 씀 |

Bayer 행렬 (값 ÷ 16 = 0~1 임계값):

```
 0  8  2 10
12  4 14  6
 3 11  1  9
15  7 13  5
```

구형 음영(행성, 나무 수관)은 표면 법선과 빛 방향(왼쪽 위 앞)의 내적에 디더링 값을 조금 더해 5단계 팔레트 중 하나를 고른다. 가장자리 한 줄은 외곽선 색이다.

## 4. 스프라이트 표기법

작은 스프라이트는 **문자열 배열**로 정의한다. 한 글자가 한 픽셀이고 `.`은 투명이다. 글자마다 색을 매핑한다. 좌우 반전은 각 줄을 뒤집어 그린다.

```js
// 물고기 9×5, 머리가 오른쪽
const FISH = [
  '....kkkk.',
  'kk.kcccwk',
  'ktkccckck',
  'kk.kddddk',
  '....kkkk.',
] // k 외곽선, c 몸, d 배·꼬리, t 꼬리, w 반짝임
```

| 스프라이트 | 크기 | 비고 |
|---|---|---|
| 신랑 | 7 × 11 | 항상 왼쪽. 걷기 2프레임(다리 줄만 교체), 걸을 때 1픽셀 들썩임 |
| 신부 | 7 × 11 | 항상 오른쪽. 신랑과 반 박자 엇갈려 들썩임 |
| 물고기 (마을 방명록) | 9 × 5 | 색 6종. 멀리서는 한 가지 그림자 색으로 그림 |
| 별 (우주 방명록) | 1픽셀 + 십자 반짝임 | 새 별은 한 단계 크게 |
| 강아지 (마을) | 10 × 6 | 달리기 2프레임, 앉으면 꼬리 흔들기 |
| 거북이 (마을) | 15 × 7 | 옆모습. 다리 2프레임 |
| 나무 | 22 × 26 캔버스 | 구형 음영 수관 + 줄기. 꽃 핀 변형 있음 |

캐릭터 색 매핑:

| 글자 | 색 | 쓰임 |
|---|---|---|
| `k` | `#2a1a2e` | 외곽선 |
| `n` | `#2a2030` | 신랑 머리 |
| `N` | `#7a4a30` | 신부 머리 |
| `s` | `#f2c29a` | 피부 |
| `w` | `#f4efe6` | 셔츠·드레스 |
| `u` | `#2f3b62` | 정장 |
| `r` | `#d04a3a` | 넥타이 |
| `p` | `#f29bb5` | 부케·하트 |
| `y` | `#f6c85f` | 베일 장식 |
| `g` | `#c9c6c0` | 드레스 그림자 |

## 6. 청첩장 UI (게임 밖)

모달, 인트로, 안내 문구, 토스트처럼 게임 조작이 아닌 화면 요소다. **장난스럽지 않고 진지하게** 보이는 것이 목표다. 픽셀 폰트, 깎인 모서리, 끊어지는 애니메이션을 쓰지 않는다.

### 글꼴

- **나눔명조**(Nanum Myeongjo, OFL): 인트로, 모달 본문, 화면 위 이름 등 청첩장 글자 전체. 결혼식 분위기에 맞는 명조체.
  - `next/font/google`로 넣는다. 빌드할 때 받아서 우리 도메인에서 내보내고(외부 CDN 아님), 한글을 유니코드 조각으로 나눠 화면에 쓰인 글자 조각만 내려받는다.
  - 대체 글꼴: `'Nanum Myeongjo', 'AppleMyungjo', serif`.
- 크기: 본문 15px(줄간격 1.8), 보조 13px, 작은 설명 12px, 섹션 제목 17px, 이름 22~26px. 굵기는 보통(400)과 강조(700).
- 갈무리11(픽셀 폰트)은 게임 화면의 이름표·말풍선·조작 버튼에만 쓴다.

### 색

| 토큰 | 값 | 쓰임 |
|---|---|---|
| `--bg` | `#faf8f5` | 모달·본문 바탕 (따뜻한 흰색) |
| `--surface` | `#ffffff` | 카드, 입력칸 |
| `--text` | `#222222` | 본문 |
| `--sub` | `#6b6b6b` | 보조 글자 |
| `--muted` | `#9b9b9b` | 설명, 날짜, 개수 |
| `--line` | `#ebe6df` | 구분선, 테두리 |
| `--accent` | 테마별 | 섹션 라벨, 강조, 주 버튼 |
| `--heart` | `#d9738e` | 이름 사이의 ♥ 에만 |

테마별 강조색: 우주 `#4b4590`(차분한 남보라), 마을 `#2f6b5e`(짙은 청록).

### 모양

- 모서리: 모달·카드 16px, 버튼·입력칸 10px, 사진 썸네일 6px.
- 테두리는 1px `--line`. 그림자는 모달에만 옅게.
- 애니메이션은 부드럽게(ease-out, 0.2~0.3초). 페이드·살짝 떠오르기 정도만.

### 섹션 제목

영문 소문자 라벨 + 한국어 제목 두 줄로 쓴다. 장식 기호(✦ 등)는 쓰지 않는다.

```
INVITATION        ← 12px, 굵게(700), 자간 0.18em, --accent
초대합니다          ← 17px, 600
```

| 영문 | 한국어 |
|---|---|
| INVITATION | 초대합니다 |
| WEDDING DAY | 예식 일시 |
| LOCATION | 오시는 길 |
| CONTACT | 연락처 |
| ACCOUNT | 마음 전하실 곳 |
| GALLERY | 사진 |
| GUESTBOOK | 방명록 |

### 문구

- 존댓말, 짧고 담백하게. 이모지·말장난·느낌표를 쓰지 않는다.
- 버튼은 동작을 그대로 쓴다: "방명록 남기기", "주소 복사", "전화", "문자".
- 테마 연출 문구("별이 떴어요", "물고기가 늘었어요")는 게임 화면의 토스트에만 쓴다. 모달 본문에서는 방명록 안내 한 줄만 예외로 둔다("남겨 주신 메시지는 바다의 물고기 한 마리가 됩니다").

## 7. 새 테마 체크리스트

1. `docs/PLANNING.md` 2장 테마 비교표의 칸을 모두 채운다.
2. 팔레트를 이 문서 5장에 추가한다.
3. 정할 것: 월드 배경, 이동 가능 영역, 장소 3곳의 좌표(들어가기 판정 반경 12픽셀), 충돌 영역, 시작 위치, 자동 이동 경유지
4. 방명록 오브젝트: 글 id 해시로 위치·색을 정하는 규칙, 새 글 연출, 탭 판정 반경
5. 장식은 적게 시작한다. 고정 장식 몇 개와 움직이는 장식 2~3개면 충분하다.
6. 모달 헤더 색을 정한다.
