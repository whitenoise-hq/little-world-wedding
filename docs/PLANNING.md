# 기획: 리틀 플래닛 웨딩

게임처럼 캐릭터를 움직이며 둘러보는 모바일 청첩장 템플릿이다. 템플릿은 하나만 두고, 커플마다 데이터만 바꿔 끼워 각자 고유한 주소를 준다.

- 참고한 청첩장: https://our-little-wedding.vercel.app/village/ (코드나 그림은 가져다 쓰지 않고 구조만 참고)
- 목업: [mockup/index.html](mockup/index.html). 브라우저로 열면 바로 움직여 볼 수 있다.

## 1. 서비스 구조

```
{도메인}/admin     → 어드민 (청첩장 생성·수정, 운영자 1명만 사용)
{도메인}/{slug}    → 커플별 청첩장 (템플릿은 모두 같음)
```

| 항목 | 결정 |
|---|---|
| 프레임워크 | Next.js. `/[slug]` 동적 라우트 하나로 모든 청첩장 처리 |
| DB·저장소 | Supabase (DB, 사진 스토리지, 어드민 로그인) |
| 게임 화면 | 2D 캔버스 픽셀아트. 무거운 엔진(three.js 등) 없이 가볍게 |
| 어드민 | 운영자만 관리. 신랑·신부 로그인 없음 |
| 배포 | Vercel |

### slug 규칙

- 영어 소문자 8자리 무작위 문자열 (예: `/ejdushfe`). 경우의 수 약 2,000억 개라 다른 사람이 추측해서 찾기 어렵다.
- 대소문자를 섞지 않는다. 카톡·문자로 전달하거나 손으로 칠 때 헷갈리지 않게 하려는 것이다.
- `crypto.getRandomValues`로 생성한다. `Math.random`은 쓰지 않는다.
- DB에 unique 제약을 걸고, 겹치면 다시 생성한다.
- 어드민에 "주소 다시 만들기" 버튼을 둔다. 링크가 원치 않는 곳에 퍼졌을 때 쓴다.

```ts
const ALPHABET = 'abcdefghijklmnopqrstuvwxyz'
const SLUG_LENGTH = 8

export function generateSlug(): string {
  const bytes = crypto.getRandomValues(new Uint8Array(SLUG_LENGTH))
  return Array.from(bytes, (b) => ALPHABET[b % ALPHABET.length]).join('')
}
```

## 2. 컨셉: 둘만의 작은 행성

마션처럼 붉은 행성에 두 사람이 정착했다는 설정이다. 행성 아래로는 우주가 펼쳐지고, 하객이 방명록을 남기면 그 우주에 별이 하나씩 늘어난다.

- **행성:** 위에서 내려다본 완전한 원형. 걷는 면은 평평하고, 가장자리 밖으로는 못 나간다. 왼쪽 위에서 빛이 비치는 구형 음영과 대기층으로 공처럼 보이게 한다.
- **화면 배율:** 저해상도로 그린 뒤 3배 확대해 픽셀을 또렷하게 보여준다. 행성이 화면보다 크고, 카메라가 캐릭터를 따라 상하좌우로 움직인다.
- **그림 스타일:** 색 수를 제한한 팔레트, 디더링 음영, 모든 물체에 어두운 외곽선. 픽셀 폰트는 갈무리(Galmuri11).

## 3. 장소와 모달

| 장소 | 그림 | 모달 내용 |
|---|---|---|
| 우리 집 | 마션풍 컨테이너형 거주 모듈 (태양광 패널, 안테나, 둥근 창, 착륙 다리) | 인사말, 일시, 장소, 오시는 길, 연락처, 계좌 (한 모달에 스크롤) |
| 사진 | 투명 돔 온실 (해바라기, 토마토 덩굴, 꽃 화단, 문 옆 화분) | 사진 갤러리 |
| 방명록 | 땅 끝 전망대의 망원경 (금속판 바닥과 테두리 불빛으로 영역 표시) | 방명록 쓰기·목록 |

### 우리 집 모달 (위에서 아래로)

1. **인사말:** 인사말 글, 양가 부모님 성함과 신랑·신부 이름
2. **예식 일시:** 날짜·요일·시간, 달력(해당 날짜 표시), D-day
3. **예식 장소:** 예식장 이름·홀, 주소(복사 버튼), 카카오맵, 길찾기 버튼(카카오맵, 네이버지도, 티맵)
4. **오시는 길:** 지하철, 버스, 주차, 기타 안내 (어드민에서 항목 추가)
5. **연락하기:** 왼쪽 신랑, 오른쪽 신부 두 열. 이름과 전화·문자 아이콘. "혼주에게 연락하기"를 펼치면 양가 아버지·어머니 연락처가 나온다.
6. **마음 전하실 곳:** 신랑 측 / 신부 측 아코디언. 사람마다 은행, 계좌번호, 예금주, 복사 버튼. 카카오페이 송금 버튼은 선택.

### 망원경 = 방명록

- 입력: 이름, 메시지, 비밀번호(작성자가 직접 삭제할 때 사용)
- 글을 남기면 모달이 닫히고, 별똥별이 날아가 아래 우주에 새 별로 자리 잡는다.
- 별 하나가 글 하나다. 별 위치는 글 id로 정해지므로 다시 들어와도 같은 자리에 있다.
- 우주의 별을 탭하면 그 별의 이름과 글이 말풍선으로 뜬다.
- 모달 안에는 전체 글 목록도 같이 보여준다.
- 운영자는 어드민에서 어떤 글이든 삭제할 수 있다. 스팸 방지 대책이 필요하다.

### 행성 장식 (모달 없음)

- 고정: 탐사 로버, 위성 안테나, 하트 깃발, 가로등, 보라색 크리스탈, 빛나는 외계 식물, 작은 연못, 크레이터, 장소로 이어지는 길
- 움직임: 거주 모듈과 온실 사이 줄전구, 가끔 지나가는 UFO, 하늘의 별똥별, 반짝이는 별, 깜빡이는 안테나 불빛

## 4. 캐릭터

- 7×11 도트의 신랑·신부. 신랑은 항상 왼쪽, 신부는 항상 오른쪽에 붙어서 걷는다. 이동 방향에 따라 좌우로 돌아보기만 하고 자리는 바뀌지 않는다.
- 머리 위에 이름표 하나: `원재 ♥ 은빈` (가운데 하트)
- 걸을 때 다리가 움직이고 몸이 살짝 들썩인다.
- 나중에 어드민에서 헤어스타일과 옷 색을 고를 수 있게 한다 (둘을 닮게 만드는 것이 핵심).

## 5. 조작

| 요소 | 위치 | 동작 |
|---|---|---|
| 조이스틱 | 왼쪽 아래, 고정형 | 미는 방향과 세기만큼 걷기. 가운데 작은 데드존 |
| 플로팅 버튼 3개 (집, 사진, 방명록) | 오른쪽 아래 | 누르면 해당 장소까지 자동으로 걸어감. 조이스틱을 만지면 자동 이동 취소 |
| 들어가기 | 가운데 위쪽 | 장소 가까이 가면 뜸. 누르면 모달 열림 |
| 키보드 (PC) | - | 방향키·WASD 이동, E 키로 들어가기 |

### 모바일 웹에서 챙길 것

- 조이스틱 조작 중 페이지 스크롤·확대 막기 (`touch-action: none`)
- 카톡 인앱 브라우저의 왼쪽 끝 스와이프(뒤로 가기)와 겹치지 않게 가장자리에서 띄우기
- 아이폰 하단 홈 바와 겹치지 않게 safe-area 반영
- 처음 들어오면 "조이스틱이나 버튼으로 움직여 보세요" 안내를 한 번 띄움

## 6. 어드민 입력 항목 (청첩장 1건)

| 구분 | 항목 |
|---|---|
| 기본 | slug(자동 생성, 재발급), 공개/비공개 |
| 인물 | 신랑·신부 이름, 양가 부모님 성함 |
| 인사말 | 인사말 글 |
| 예식 | 날짜·시간, 예식장 이름, 홀, 주소, 좌표, 교통 안내 |
| 연락처 | 신랑, 신부, 양가 부모님 전화번호. 사람마다 노출 여부 |
| 계좌 | 신랑 측·신부 측 계좌 목록. 사람마다 노출 여부, 카카오페이 링크(선택) |
| 사진 | 사진 여러 장(순서 변경), 카톡 공유용 대표 사진 |
| 꾸미기 | 캐릭터 헤어·옷 색, 대표 색, 배경음악 |
| 방명록 | 글 목록, 삭제 |

## 7. 꼭 챙길 것

1. **카톡 공유 미리보기:** 청첩장마다 OG 태그(제목, 설명, 대표 사진)를 다르게 생성한다. 가장 중요하다.
2. **사진 최적화:** 업로드할 때 리사이즈·압축한다.
3. **배경음악:** 꺼진 상태로 시작한다.
4. **저작권:** 그림·폰트·음악은 상업적 이용이 가능한 것만 쓴다. 갈무리 폰트는 OFL이다.

## 8. 진행 순서

1. 데이터 구조, 어드민, `/[slug]` 페이지 (게임 없이 일반 청첩장 형태)
2. 픽셀아트 행성 게임 화면을 붙이고 장소와 데이터 연결
3. 카톡 공유, 방명록 관리, 사진 최적화

## 9. 아직 정하지 않은 것

- 참석 여부 받기(RSVP)를 넣을지, 넣는다면 어디에 둘지
- 게임 없이 세로로 한 번에 보는 "바로 보기" 화면을 둘지
- 그림을 직접 그린 픽셀아트로 계속 갈지, 캐릭터만 외주나 구매 소스로 바꿀지
