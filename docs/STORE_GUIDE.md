# 스마트스토어 이미지 가이드

네이버 스마트스토어 상품 이미지(대표·추가)와 상세설명 이미지를 만들 때의 기준. 어느 테마, 누가 만들든 같은 디자인으로 나오게 하는 것이 목적이다.

- 만든 이미지는 레포에 커밋하지 않는다(`out/store/{테마}/`에 만든다. `out/`은 git 제외). 기준 이미지 4장만 `docs/store/reference/`에 둔다.
- 새로 만든 결과물은 기준 이미지와 나란히 놓고 비교해서 색·배치·글자 크기가 같은지 확인한다.

기준 이미지는 마을 테마로 만들었다. 다른 테마는 아래 "테마별 값"의 색과 문구만 바꾼다.

## 1. 화면 캡처

- 샘플 청첩장(마을 `/seavilla`, 우주 `/marsland`, 공항 `/loveport`)을 실제 배포 주소에서 캡처한다. 목업이나 로컬 화면을 쓰지 않는다.
- 크롬 헤드리스, 화면 390×844, 배율 3(결과 1170×2532), 모바일·터치 모드.
- 캡처할 화면

| 이름 | 방법 |
|---|---|
| 표지 | 접속하고 2~3초 뒤 (들어가기·청첩장 바로 보기 버튼이 보이는 상태) |
| 게임 | 들어가기 → 안내 문구가 사라지도록 5초 이상 기다린 뒤 |
| 장소 앞 | 플로팅 버튼(청첩장·사진·방명록)을 누르고 6초 기다린 뒤. 들어가기 버튼이 떠 있어야 한다 |
| 장소 모달 | 장소 앞에서 들어가기 버튼(`button.enter`)을 누른 뒤. 청첩장 모달은 맨 위와 맨 아래 두 장 |
| 바로 보기 | 표지에서 "청첩장 바로 보기"를 누른 뒤 맨 위 |

- 캡처 전에 샘플 방명록에 이상한 방문자 글이 없는지 어드민에서 확인한다.
- 사진 갤러리는 샘플에 상업 이용 가능한 커플 사진이 충분히(10장 이상) 있을 때만 캡처해서 쓴다. 없으면 갤러리 화면 대신 사진 장소 앞 게임 화면을 쓴다.
- 지도 표시가 "준비 중"인 동안은 지도가 보이는 캡처를 쓰지 않는다.

## 2. 공통 디자인 값

### 글꼴

- 제목: **나눔명조 Bold**
- 본문·라벨: **나눔고딕** Regular / Bold
- 둘 다 OFL이라 상업 이용 가능. Google Fonts 저장소(`google/fonts`의 `ofl/nanummyeongjo`, `ofl/nanumgothic`)에서 받는다.
- 픽셀 폰트(갈무리)는 이미지 문구에 쓰지 않는다. 픽셀은 캡처된 게임 화면과 로고에만 있다.

### 공통 색

| 이름 | 값 | 쓰는 곳 |
|---|---|---|
| cream | `#f7f2e9` | 기본 배경 |
| paper | `#fffdf9` | 밝은 섹션 배경 |
| ink | `#28261f` | 제목·본문 |
| muted | `#6e6860` | 설명 글 |
| accent | `#c8593c` | 영문 라벨, 마지막 단계 번호 원 |
| line | `#e6dccb` | 목록 구분선 |
| 카드 | `#ffffff` | 글 카드 |

### 휴대폰 틀

- 틀 색 `#1c1c1e`, 화면 둘레 두께는 상세(848px) 기준 12px, 상품 이미지(1000px) 기준 14px.
- 모서리: 상세 기준 틀 52px / 화면 42px. 상품 이미지는 화면 너비의 12%.
- 옅은 그림자(아래로 퍼지는 검정 15~25%). 테두리 선은 쓰지 않는다.

## 4. 대표이미지 (1000×1000, 1장)

- **글자를 넣지 않는다.** 네이버 쇼핑은 대표이미지의 글자·테두리를 싫어한다.
- 배경 mint, 가운데에 지름 720px 원(대표이미지 원 색).
- 휴대폰 두 대: 왼쪽 표지(높이 760, 위에서 150), 오른쪽 게임 화면(높이 820, 위에서 90). 두 대가 가운데를 기준으로 살짝 엇갈린다.

## 6. 상세 이미지 (가로 848px, 16장)

한 장의 세로 랜딩 페이지로 만든 뒤 섹션마다 잘라서 올린다. 스마트스토어 상세설명은 "직접 작성"에서 이미지를 순서대로 올리고, 맨 위에 핵심 문구 몇 줄을 글로 넣는다(이미지 속 글자는 검색에 안 잡힌다).

### 섹션 공통 (기준: detail-phone-section.jpg, detail-text-section.jpg)

- 섹션 여백 위아래 110px, 좌우 72px, 가운데 정렬
- 영문 라벨: 나눔고딕 Bold 20px, 글자 간격 0.18em, accent
- 제목: 나눔명조 Bold 50px, 줄 간격 1.35, 라벨 아래 18px
- 설명: 나눔고딕 25px, muted, 줄 간격 1.75, 제목 아래 24px
- 휴대폰: 두 대면 각 너비 330px·간격 36px, 한 대면 380~420px. 설명 아래 64px
- 글 카드: 흰 바탕, 모서리 28px, 안쪽 여백 40px
- 번호 원: 지름 58px, dark 바탕 흰 숫자. 마지막 단계만 accent
- 칩: 둥근 알약 모양, cream 바탕, dark 글자, 19px Bold
- 배경은 섹션마다 cream / paper / mint / dark를 번갈아 써서 구분한다. 그림자·테두리 선은 휴대폰 틀 말고는 쓰지 않는다.

### 구매 후 진행 (12번)

1. 네이버 톡톡으로 안내 받기 — 결제 후 톡톡으로 자료 보내는 방법을 알려 드려요. 먼저 톡톡으로 말을 걸어 주셔도 좋아요.
2. 청첩장 자료 보내기 — 안내받은 메일 또는 톡톡으로 아래 준비물을 보내 주세요.
3. 청첩장 링크 받기 — 자료를 받은 날부터 영업일 기준 2일 안에 완성된 청첩장 링크를 보내드려요.
4. 확인하고 수정 요청하기 — 직접 걸어 보시고 고칠 부분을 알려 주세요. 완성 후 2회까지 무료로 수정해 드려요.
5. 하객에게 공유하기 — 카카오톡이나 문자로 링크만 보내면 끝이에요.

### 준비물 (13번)

신랑·신부 이름 / 예식 날짜와 시간 / 예식장 이름, 홀, 주소(오시는 길은 아시는 만큼만) / 인사말(없으면 기본 문구) / 연락처(신랑·신부, 공개를 원하시는 양가 부모님) / 계좌번호(공개를 원하시는 분만, 카카오페이 송금 링크 선택) / 사진 최대 20장(카카오톡 미리보기 사진도 골라 주세요) / 배경음악 사용 여부

## 7. 지켜야 할 규칙

- **운영 정책 값은 한 번에 바꾼다.** 제작 기간(영업일 2일), 수정 횟수(2회), 이용 기간(예식일 후 3개월), 사진 최대 장수(20장, `MAX_PHOTOS`)는 상세 이미지, 상품정보제공고시, A/S 안내, 판매자 특이사항, 톡톡 안내 문구에 모두 들어간다. 하나를 바꾸면 전부 바꾼다.
- **이메일 주소·전화번호를 이미지에 넣지 않는다.** 네이버는 외부 거래 유도로 제재할 수 있다. 메일 주소는 구매 후 톡톡으로만 알린다.
- **샘플 주소는 링크 대신 QR 코드와 주소 글자로 넣는다.** 상세설명의 외부 링크는 지워지거나 제재될 수 있다. 도메인을 바꾸면 QR과 주소도 바꾼다.
- **환불 문구는 법을 근거로 쓴다.** "어떤 경우에도 환불 불가" 같은 임의 규정은 쓰지 않는다. 제작 전 전액 환불, 판매자 귀책 무상 수정을 같이 적는다.
- **없는 기능을 쓰지 않는다.** 지도 표시처럼 아직 안 된 기능은 이미지와 문구에서 뺀다.
- 버튼 이름은 실제 화면과 같아야 한다(청첩장·사진·방명록, 청첩장 보기, 청첩장 바로 보기). 화면이 바뀌면 다시 캡처한다.
